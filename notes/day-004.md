## Học được
- Lũy thừa: `3 ** 2` → `9`
- Số có ý nghĩa nên đặt tên biến (`c = 300000000`), gõ đúng 1 lần, tránh sai số 0
- `.replace(ký_tự, "")` = xóa ký tự đó
- Trong `return` viết được cả phép tính: `return float(...) / 100`
- Phần trăm = chia 100: `15%` → `0.15`
- Bọc hàm: việc trên chuỗi làm trước, `int`/`float` bọc ngoài cùng
- Dấu nháy `' '` trong kết quả máy chấm = chuỗi
- Code trong cửa sổ ≠ code Python chạy nếu **chưa Ctrl + S**
- Đề CS50 ghi "output E" → chỉ in con số (check50 thật sẽ chấm sai nếu in thêm chữ)
